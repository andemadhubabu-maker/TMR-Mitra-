# 🚆 TMR Mitra – Version 1 Beta

*Right information · at the right time · in the right format*

A control-message and report helper for Train Managers (TMRs). It works **fully offline** and keeps **all data on your own phone**. It is a personal aid, **not an official Railway tool**. It only drafts wording; rule books and Control's orders always come first. This is a Beta, so please report bugs and wrong wording.

![Logo](./logo.png)

## What it does
- Guided messages: 19 categories, 139 scenarios, Full and Short formats (278 message formats).
- One "Where did it stop?" choice (mid-section, passing, platform, yard), repeated stoppages with an automatic total, and a Follow-up: Train Ready / Started message.
- Quick entry by typing or voice, Emergency window, recheck-before-send warnings.
- Evidence: photo, video, audio note, multi-camera, stamp.
- Troubleshooting checklists, stop timer, detention calculator.
- Reports: TMR, Loco Pilot and Joint, with signature pad, PDF and WhatsApp text.
- **My Library**: ROM, SOB, safety circulars, flyleaf, SOP, ready reckoner, and **Rule book amendments** (add each AS slip with number, date, note, photo or PDF, or add a range such as AS 11 to 23).
- Reuse an earlier message for a follow-up.
- My record (PME / RC / first aid box / signal certificate reminders), important numbers, saved messages, shift log, Night and Outdoor modes, Training mode, Telugu/Hindi titles.
- Depot helpers: starter pack, install check, backup reminder.

## Install (free, 1 minute)
Host these files with GitHub Pages (see [docs/INSTALL.md](docs/INSTALL.md)), then on Android open the link in Chrome → ⋮ → **Install app**. Open once with internet, then it works offline.

# Install and publish

## For the person publishing (once)
1. Create a GitHub repository (for example `tmr-mitra`).
2. Upload **all files and folders** of this package to the `main` branch root (keep `fonts/` and `docs/`).
3. Settings → Pages → Source: `main` / root → Save. The link appears in 1–2 minutes.
4. Put that link in `[APP LINK]` of the share messages in `docs/messages/`, and your name in `[Your name]`.

## For colleagues
**Android (Chrome):** open the link → ⋮ → *Install app* (or *Add to Home screen*). Open once with internet and wait a few seconds. After that it works without internet.
**iPhone (Safari):** open the link → Share → *Add to Home Screen*.

Check: ⚙ Station codes, contacts & backup → *Check now*. It should say the saved copy for offline use is found.

## Updating
Upload the new files over the old ones. Open the app with internet; the new version loads on the next open. Your data is kept. Back up monthly.
